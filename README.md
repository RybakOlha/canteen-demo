# Шкільна їдальня — Canteen Lab

Окрема навчальна вебсторінка для Місії 02 курсу NextLab / AI Code Challenge.

## Структура

- `index.html` — семантична розмітка
- `css/style.css` — адаптивні стилі
- `js/app.js` — логіка асинхронного завантаження меню

## Як відкрити

Скопіюйте папку `canteen-demo` до папки `student-app` поруч із `devmate`. У VS Code відкрийте термінал у `student-app` і запустіть:

```bash
python3 -m http.server 8000
```

Відкрийте `http://localhost:8000/canteen-demo/`.

Якщо сервер уже працює на іншому порту, використайте цей порт.

## Що перевіряти

1. Кнопка «Завантажити меню» — очікування ~1,5 секунди та 4 картки.
2. Під час очікування обидві кнопки заблоковані.
3. Кнопка «Імітувати помилку» — повідомлення про помилку.
4. Після помилки можна повторно завантажити меню.

Це навчальна імітація. Дані та ціни вигадані, сервер або LLM не використовуються.
